# ADR 0001: 初始化文档优先的 vibecoding 仓库框架

## 状态

Accepted

## 背景

当前仓库用于沉淀 AI infra 转型项目。为了让后续 AI 辅助开发更稳定，需要先建立规则、文档入口、提交规范和基础协作结构。

## 决策

采用轻量、文档优先的仓库框架：

- 使用 `AGENTS.md` 作为 AI coding agent 的入口规则。
- 使用 `rules/` 存放长期有效的工程和协作规则。
- 使用 `docs/README.md` 作为文档索引。
- 使用 `docs/adr/` 记录重要架构和流程决策。
- 使用 `.gitmessage` 固化中文 commit message 风格。
- 使用 `.github/` 提供 issue 和 PR 模板。

## 原因

- 目录结构足够轻，不会在项目初期引入过度工程化。
- AI agent 每次任务都有明确入口，可以减少上下文漂移。
- 中文 commit 和文档规则更符合个人学习和复盘场景。
- ADR 可以记录关键判断，方便后续回看项目演化。

## 后果

- 后续新增项目、实验或代码时，需要同步更新文档索引。
- 重要方向变化应新增 ADR。
- 如果仓库未来开源，需要额外补充 LICENSE、安全说明和更正式的贡献指南。
