# Documentation Rules

## 文档分类

- `docs/README.md`：文档入口。
- `docs/adr/`：Architecture Decision Records。
- `docs/projects/`：项目级设计和路线图，后续可逐步迁移。
- `docs/benchmarks/`：benchmark 方法、结果和报告。
- `docs/notes/`：探索笔记和临时研究记录。

## 设计文档应包含

- 背景。
- 目标。
- 非目标。
- 系统边界。
- 关键设计。
- 验证方式。
- 风险和规避。
- 后续路线。

## Benchmark 文档应包含

- 数据集和 query set。
- 硬件环境。
- 运行命令。
- 指标定义。
- 原始结果路径。
- 图表和解释。
- 结论适用范围。

## 文风

- 优先清晰，少用空泛口号。
- 重要术语第一次出现时解释。
- 对外叙事要突出工程问题、约束和验证，而不是只描述功能。
